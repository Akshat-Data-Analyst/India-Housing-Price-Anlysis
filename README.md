# 🏠 India Housing Price Analysis

## 📌 Project Overview

India Housing Price Analysis is a data analytics project developed using Python and Streamlit.

The main objective of this project is to analyze housing data across different states and cities in India, understand property price trends, and identify useful insights through data visualization.

This project includes data cleaning, Exploratory Data Analysis (EDA), and an interactive Streamlit dashboard.

## 🎯 Project Objectives

* Analyze housing prices across different Indian states and cities.
* Perform data cleaning using Python.
* Explore property prices based on BHK, size, and property type.
* Understand furnishing status and property age distribution.
* Create interactive visualizations using Plotly.
* Develop a user-friendly Streamlit application.

## 🛠️ Technologies Used

## 📊 Key Analysis & Visualizations

The project includes the following visualizations:

1. State-wise Average Property Price
2. City-wise Average Property Price
3. Property Type Distribution
4. BHK Distribution
5. Average Price by BHK
6. Furnishing Status Distribution
7. Property Size vs Price Analysis
8. Property Age Distribution

## 📈 Key Insights

* The dataset contains 250,000 housing records.
* Karnataka has the highest average property price among the analyzed states.
* Bangalore has the highest average property price among the analyzed cities.
* Villas, Independent Houses, and Apartments are analyzed.
* Property prices are explored based on size, BHK, and furnishing status.

